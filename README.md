# Honeypot-Setup-and-Intrusion-Monitoring
Cybersecurity project demonstrating honeypot deployment, intrusion detection, and attacker activity monitoring.

## Project Overview

This project demonstrates the deployment of a honeypot environment to monitor, detect, and analyze unauthorized access attempts. The honeypot was configured to attract potential attackers and record their activities for security analysis.

## Objectives

* Understand the purpose and functionality of honeypots.
* Deploy and configure a honeypot environment.
* Monitor intrusion attempts and malicious activities.
* Analyze attacker behavior and collected logs.

## Tools Used

* Honeypot Software
* Virtual Machine Environment
* Windows/Linux Operating System
* Network Monitoring Tools

## Activities Performed

### 1. Honeypot Deployment

* Installed and configured a honeypot system.
* Configured network settings for monitoring.
* Verified accessibility of the honeypot service.

### 2. Intrusion Monitoring

* Monitored incoming connection attempts.
* Recorded login attempts and network activity.
* Collected logs generated by suspicious interactions.

### 3. Log Analysis

* Reviewed captured events and connection details.
* Identified source IP addresses and attack patterns.
* Analyzed potential reconnaissance and intrusion attempts.

## Findings

* Successfully deployed and monitored a honeypot environment.
* Captured unauthorized connection attempts.
* Observed attacker behavior and network reconnaissance activities.
* Generated logs useful for security investigations.

## Conclusion

This project provided practical experience in deception technologies, intrusion monitoring, and security log analysis. It demonstrated how honeypots can be used to detect and study malicious activity while improving overall security awareness.
